Automatisch: GMX → Fireworks

Das Backend loggt sich bei GMX ein, erstellt einen neuen Alias, registriert damit einen Fireworks-Account, bestätigt die OTP-Email und generiert den API-Key. Alles automatisch in ~3 Minuten.

Typischer Flow: Login → Alias rotieren → Signup → OTP → Verify → API Key → Pool

opencode — fertige Konfiguration

Erstelle ~/.config/opencode/opencode.json mit diesem kompletten Inhalt:

{ "provider": { "fireworks-ai": { "npm": "@ai-sdk/fireworks", "name": "Fireworks AI (SINator)", "options": { "baseURL": "https://sinator.delqhi.com/inference/v1" }, "models": { "deepseek-v4-pro": { "id": "fireworks/deepseek-v4-pro", "name": "DeepSeek V4 Pro", "options": { "thinking": { "type": "enabled", "budgetTokens": 64000 } }, "limit": { "context": 1048576, "output": 65536 } }, "glm-5p1": { "id": "fireworks/glm-5p1", "name": "GLM 5.1", "options": { "thinking": { "type": "enabled", "budgetTokens": 32000 } }, "limit": { "context": 202752, "output": 32768 } }, "kimi-k2p6": { "id": "fireworks/kimi-k2p6", "name": "Kimi K2.6", "options": { "thinking": { "type": "enabled", "budgetTokens": 32000 } }, "limit": { "context": 262144, "output": 32768 } } } } }, "agent": { "SIN-Zeus": { "model": "fireworks-ai/deepseek-v4-pro" } } }
