Einrichtung

So bindest du SINator in deine Tools ein.

opencode / Cursor / Continue einrichten

opencode

In deiner ~/.config/opencode/config.json (oder über opencode config set):

"baseURL": "http://localhost:8888/inference/v1", "apiKey": "pool"

Cursor

In den Cursor Settings unter Models einen neuen Provider anlegen:

  • Base URL: http://localhost:8888/inference/v1
  • API Key: pool

Danach kannst du jedes Modell auswählen, das Fireworks AI anbietet.

Continue (VS Code / JetBrains)

In deiner ~/.continue/config.json:

{ "models": [{ "provider": "openai", "apiBase": "http://localhost:8888/inference/v1", "apiKey": "pool", "model": "accounts/fireworks/models/llama-v3p1-405b-instruct" }] }

OpenAI SDK (Python)

import openai client = openai.OpenAI( base_url="https://sinator.delqhi.com/inference/v1", api_key="pool", ) response = client.chat.completions.create( model="accounts/fireworks/models/llama-v3p1-405b-instruct", messages=[{"role": "user", "content": "Hi!"}], )
