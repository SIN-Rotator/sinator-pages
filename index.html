Wie es funktioniert

1. SINator erstellt GMX Email-Alias (z.B. storm-fox-123@gmx.de) 2. Registriert neuen Fireworks AI Account mit dem Alias 3. Liest OTP-Bestätigung automatisch aus GMX Postfach 4. Loggt in Fireworks ein, füllt Onboarding aus 5. Erstellt API Key → speichert in lokalen Pool 6. Dashboard zeigt alle Keys, Status, Health
